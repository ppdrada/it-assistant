# 🤖 IT Assistant

Projeto de um assistente de suporte de TI desenvolvido em Node.js.

A ideia é construir o projeto aos poucos...

## Estrutura do projeto

- `data/` → onde ficam os dados que o sistema conhece, como tickets e artigos da base de conhecimento.

- `utils/` → funções auxiliares que podem ser usadas em diferentes partes do projeto.

- `services/` → responsável por executar ações usando os dados do sistema.

- `mlWorker.js` → responsável pela parte de Machine Learning.
- `index.js` → ponto de entrada do projeto.
